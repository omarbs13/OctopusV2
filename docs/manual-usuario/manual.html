Cómo usar este manual

Este manual explica, paso a paso, cómo operar el sistema de punto de venta: desde la primera instalación hasta el cierre de caja, los reportes y la administración. Está pensado para dos tipos de lectores:

  • Cajeros: pueden ir directo a los capítulos Primeros pasos, Caja y turnos y Punto de venta.
  • Administradores: conviene leer el manual completo, empezando por Puesta en marcha.

Introducción

¿Qué es el sistema?

Es un punto de venta de escritorio para Windows y Linux. Funciona sin conexión a internet: toda la información del negocio (productos, ventas, turnos, clientes) se guarda en la misma computadora, con respaldos automáticos diarios.

Con el sistema puede:

  • Vender con lector de códigos de barras, teclado o pantalla táctil.
  • Cobrar en efectivo, tarjeta, transferencia, nota de crédito o a crédito.
  • Imprimir tickets y abrir el cajón de dinero.
  • Controlar turnos de caja con arqueo ciego, Corte X y Corte Z.
  • Administrar productos, categorías e imágenes.
  • Llevar el inventario con kárdex y alertas de existencia baja.
  • Registrar compras a proveedores.
  • Aplicar descuentos y cupones.
  • Procesar cancelaciones, devoluciones y notas de crédito.
  • Vender a crédito a clientes y registrar sus abonos.
  • Consultar reportes y exportarlos a PDF o Excel.
  • Revisar una bitácora de auditoría de todas las operaciones.

Cada persona entra con su propio usuario. Existen dos roles:

RolPara quiénQué puede hacer
AdministradorDueño, gerente o encargado.Todo: configuración, usuarios, productos, inventario, compras, reportes, bitácora y autorizar operaciones sensibles.

El detalle de cada permiso está en el Apéndice C.

Autorización de administrador

Cuando un Cajero intenta una operación que requiere permiso (por ejemplo, cancelar una venta, retirar efectivo o aplicar un descuento mayor al límite), el sistema ofrece Solicitar autorización. Un Administrador captura su usuario y contraseña en un diálogo, sin cerrar la sesión del cajero. La autorización vale para esa sola operación y vence a los 2 minutos. En la bitácora quedan registrados quién pidió la operación y quién la autorizó.

Algunas funciones se activan por módulos de la licencia. Durante los primeros 30 días (período de evaluación) todos los módulos están activos. Después, solo quedan activos los módulos contratados (ver Ayuda, licencia y respaldos).

Primeros pasos

Abrir el sistema

Al abrir la aplicación aparece la pantalla de carga, que muestra lo que está haciendo: «Verificando la base de datos…», «Respaldando la base de datos…», «Actualizando la base de datos…» (después de instalar una versión nueva) y «Preparando…». No cierre la aplicación mientras esté en esta pantalla.

Logotipo propio en la pantalla de carga Copie un archivo PNG llamado logo.png (de preferencia cuadrado, 320 × 320 px, con fondo transparente) en la carpeta de datos del sistema y reinicie. Si no conoce la ubicación de la carpeta, pídala a soporte: viene en el archivo de Exportar diagnóstico….

El sistema solo permite una ventana abierta a la vez: si lo abre de nuevo, se muestra la ventana existente.

La pantalla de carga se ve unos 2 segundos. La primera vez, la ventana principal abre maximizada; después abre como la dejó la última vez (maximizada, o con el mismo tamaño y posición). Si la posición guardada quedó fuera de la pantalla (por ejemplo, al desconectar un segundo monitor), la ventana aparece centrada.

Primera vez: crear el administrador

La primera vez que se usa el sistema aparece el asistente Crear administrador. No existe ningún usuario ni contraseña de fábrica, y no se puede entrar sin completar este paso.

  1. Escriba el Nombre completo del administrador.
  2. Elija un Usuario: de 3 a 40 caracteres (letras, números, punto, guion o guion bajo).
  3. Escriba la Contraseña (mínimo 8 caracteres) y repítala en Confirmar contraseña.
  4. Pulse Crear y continuar.
Guarde bien esta contraseña No hay recuperación por correo. Si se olvida la contraseña de un usuario, otro Administrador puede restablecerla. Por eso se recomienda crear al menos dos administradores.

Iniciar sesión

  1. Escriba su Usuario 1. No distingue mayúsculas ni acentos.
  2. Escriba su Contraseña 2.
  3. Pulse Entrar o Enter 3.

Si un administrador le creó el usuario, la contraseña inicial es temporal: al entrar por primera vez el sistema pide cambiarla (pantalla Cambiar contraseña: contraseña actual, nueva y confirmación).

Bloqueo por intentos fallidos Después de 5 intentos fallidos seguidos el usuario queda bloqueado 5 minutos, incluso si se reinicia la aplicación. Para desbloquearlo antes, un Administrador puede restablecer su contraseña.

La pantalla principal

Después de iniciar sesión se muestra la pantalla Inicio:

  • 1Área de trabajo: muestra la pantalla elegida en el menú.
  • 2Menú lateral: agrupa las opciones (Ventas, Caja, Clientes, Reportes, Catálogos…). Pulse un grupo para abrirlo o cerrarlo; la primera vez que entra, todos los grupos aparecen cerrados y después el sistema recuerda, para cada usuario, cuáles dejó abiertos. Cada opción tiene su propio ícono. El botón ☰ (o Ctrl+B), en la esquina superior izquierda, contrae el menú a solo íconos para ganar espacio; al pasar el ratón sobre un ícono se ve el nombre de la opción. Solo aparecen las opciones que su rol y la licencia permiten.
  • 3Tarjetas de indicadores: ventas del día, turno actual, productos activos, alertas de existencia, etc.
  • 4Menú de usuario (al pie del menú lateral): nombre y rol de quien está conectado, con Cambiar contraseña, Cambiar de usuario y Cerrar sesión.

Bloqueo por inactividad

Si nadie usa el sistema durante 15 minutos (configurable), la sesión se bloquea con una capa que pide la contraseña del mismo usuario. La pantalla y la venta en curso se conservan. Desde la capa también puede pulsar Cambiar de usuario.

Cambiar de usuario y cerrar sesión

Use el menú de usuario, al pie del menú lateral. Si hay una venta en curso, el sistema pide confirmación: la venta no se pierde, queda guardada a nombre de ese usuario y se le ofrece recuperarla la próxima vez que entre.

Categorías

Solo Administrador

Catálogos → Categorías. Las categorías agrupan productos (un solo nivel) y permiten filtrar los reportes de ventas e inventario.

  • Nombre: obligatorio, hasta 50 caracteres, único sin distinguir mayúsculas ni acentos («Bebidas» y «BEBÍDAS» son el mismo).
  • Descripción: opcional, hasta 200 caracteres.
  • Desactivar: la categoría deja de ofrecerse para productos nuevos; los productos que la tienen la conservan. Si tiene productos, el sistema pide confirmación indicando cuántos.
  • Eliminar: solo si no tiene productos. Si los tiene, reasígnelos o desactive la categoría.
Reportes por categoría Los reportes usan la categoría que tiene el producto al momento de consultar. Si cambia un producto de categoría, sus ventas pasadas también se mueven a la nueva.

Registrar un movimiento

Solo Administrador

Use Registrar movimiento para el inventario inicial y para ajustes.

  1. Elija el Producto. Se muestra su Existencia actual.
  2. Elija el Tipo de movimiento (ver tabla).
  3. Escriba la Cantidad (enteros o hasta 3 decimales, según la unidad). El sistema muestra la Existencia resultante.
  4. Escriba el Motivo y, si aplica, la Referencia (folio de factura o remisión).
  5. Pulse Guardar. Aparece «Movimiento registrado. Existencia: …».
TipoUso
Inventario inicialPrimera carga de existencia del producto.
EntradaMercancía recibida sin registrar una compra.
Ajuste positivo / negativoCorrecciones por conteo físico, merma, caducidad, etc.
Movimientos automáticos Las ventas, cancelaciones, devoluciones y compras generan sus propios movimientos («Salida por venta», «Devolución por venta cancelada», «Devolución de venta», «Entrada de compra», «Anulación de compra») y no se pueden registrar a mano. Un ajuste negativo no se permite si la existencia ya es negativa: registre primero una entrada o un ajuste positivo.

Movimientos (kárdex)

Inventario → Movimientos muestra el historial: fecha y hora, producto, tipo, cantidad, existencia resultante, unidad, motivo, referencia y usuario. Filtre por producto, tipo y rango de fechas. En las entradas de compra, la referencia muestra «Factura … · proveedor» y abre el detalle de la compra.

Alertas de existencia

El sistema revisa las existencias al iniciar sesión y cada hora. Si hay productos urgentes o en alerta, aparece una notificación abajo a la derecha: Existencia urgente (roja) o Existencia en alerta (naranja), con el número de productos. No interrumpen la venta.

  • Pulse la notificación para abrir Reportes → Inventario ya filtrado.
  • Pulse × para descartarla.
  • Cada usuario recibe el aviso de un producto una vez al día por nivel; si un producto pasa de «En alerta» a «Urgente», se avisa de nuevo.

Entrada de mercancía (registrar una compra)

Solo Administrador

Inventario → Entrada de mercancía registra una factura de proveedor y suma la existencia de cada producto.

  1. Elija el Proveedor (solo activos), escriba el Número de factura y la Fecha de factura (no puede ser futura; por omisión, hoy).
  2. En el buscador, escriba o escanee el producto y pulse Enter: se agrega y el cursor pasa a la cantidad.
  3. Escriba la Cantidad, pulse Tab, escriba el Costo unitario (antes de impuestos) y pulse Enter para volver al buscador.
  4. Repita con cada producto. Si agrega uno que ya está, el sistema lleva el cursor a su línea.
  5. Escriba los Impuestos de la factura (un solo importe; vacío = $0.00).
  6. Revise el Subtotal y el Total, y pulse Registrar compra.
Bonificaciones Una línea con costo $0.00 es una bonificación (producto regalado): suma existencia y se marca «Bonificación». La compra no puede tener solo bonificaciones.
Factura duplicada No se puede registrar dos veces la misma factura del mismo proveedor (sin distinguir mayúsculas ni espacios). El mensaje indica la fecha de la compra existente y ofrece Ver compra.

Anular o corregir una compra

Las compras no se editan. Para corregir un error: abra el detalle de la compra (desde Reportes → Compras o el kárdex), pulse Anular compra, escriba el Motivo y confirme. Después regístrela de nuevo con los datos correctos (puede usar el mismo número de factura).

La anulación resta de la existencia lo que la compra sumó. Se rechaza si algún producto quedaría con existencia negativa, está inactivo o ya no controla inventario; el mensaje indica qué productos lo impiden.

Caja y turnos

Módulo: Turnos y arqueo

Un turno es el período de trabajo de un usuario en la caja, desde la apertura hasta el cierre (Corte Z). Para vender se necesita un turno abierto propio. Solo puede haber un turno abierto por caja.

Abrir turno

  1. Entre a Ventas → Punto de venta (o pulse F9). Si no hay turno, aparece «No hay un turno abierto».
  2. Pulse Abrir turno.
  3. Escriba el Fondo inicial: el efectivo con el que empieza para dar cambio.
  4. Pulse Abrir turno. Si el fondo es 0, el sistema pide confirmación («Abrir sin fondo»).

Con el turno abierto, el Punto de venta muestra la barra del turno (folio, hora de apertura, usuario y número de ventas) con los botones Ingreso, Retiro y Corte Z. Si cierra la aplicación, el turno sigue abierto y continúa al volver a entrar.

Turno de otro usuario Si hay un turno abierto de otra persona, el Punto de venta se bloquea: «Hay un turno abierto de … Debe cerrarse antes de vender». El Cajero solo puede cerrar sesión; el Administrador ve Cerrar ese turno.

Ingresos y retiros de efectivo

Desde la barra del turno:

  • Ingreso: efectivo que entra a la caja sin ser venta (por ejemplo, más cambio).
  • Retiro: efectivo que sale (pago a un proveedor, depósito al banco). Un Cajero necesita la autorización de un Administrador. No se puede retirar más del efectivo esperado.

Escriba el Monto y el Motivo y pulse Guardar. Al registrarse, puede pulsar Imprimir comprobante. El movimiento recibe un folio como T-000123-02.

¿Cómo se calcula el efectivo esperado?

El efectivo que debería haber en la caja es:

+Fondo inicial
+Efectivo de las ventas (lo cobrado, ya descontado el cambio)
+Ingresos
−Retiros
−Reintegros en efectivo por devoluciones o cancelaciones
+ / −Abonos de clientes en efectivo y sus anulaciones

Los pagos con tarjeta, transferencia, nota de crédito y las ventas a crédito no forman parte del efectivo esperado; se reportan por separado.

Corte X (lectura parcial)

Caja → Corte X. Muestra las cifras del turno abierto en ese momento (ventas, canceladas, formas de pago, devoluciones, crédito, ingresos, retiros y efectivo esperado) sin cerrar el turno y sin interrumpir la venta en curso. Puede hacer los que necesite; cada uno recibe un folio X-000001. Pulse Imprimir para obtener el ticket «CORTE X — LECTURA PARCIAL - NO ES CIERRE DE CAJA».

El Administrador lo genera directamente; el Cajero necesita la autorización de un Administrador.

Corte Z (cierre del turno con arqueo ciego)

Caja → Corte Z o el botón Corte Z de la barra del turno. El cierre tiene tres pasos:

  1. Conteo: cuente el efectivo de la caja y escríbalo en Efectivo contado en caja. En este paso no se muestra cuánto debería haber (arqueo ciego). Pulse Continuar.
  2. Cifras: se muestran efectivo esperado, contado y la Diferencia (Sobrante, Faltante o Cuadrado), además de tarjeta y transferencia. Si hay diferencia, el Comentario es obligatorio. Volver a contar regresa al paso 1 (cada conteo queda registrado).
  3. Cierre: pulse Confirmar Corte Z. El turno se cierra, recibe el folio Z-000001 y se imprime el corte. Pulse Terminar.
Antes de cerrar No se puede cerrar un turno mientras su dueño tenga una venta en curso: termínela o cancélela. Si la cifra esperada cambia entre el paso 2 y el 3 (por ejemplo, una venta desde otra ventana), aparece «El turno cambió» y se muestran las cifras nuevas.

Un Administrador puede cerrar el turno de otro usuario desde el Punto de venta («Cerrar ese turno») o desde Ventas → Turnos. Si el dueño dejó una venta guardada, se avisa y se descarta.

Si la impresora falla, el cierre no se revierte: se ofrece Reintentar y el corte se puede reimprimir después.

Histórico de cortes

Solo Administrador

Caja → Histórico de cortes lista los Cortes X y Z. Filtre por tipo, fechas (hoy por omisión) y usuario. Doble clic o Ver abre el corte con las cifras originales; Reimprimir lo imprime con la leyenda «REIMPRESIÓN». Los cortes no se pueden modificar ni borrar.

Turnos y Mi turno

  • Ventas → Turnos Solo Administrador: todos los turnos con estado (Abierto/Cerrado), usuario, apertura, cierre, total vendido y diferencia. El detalle tiene las pestañas Ventas, Movimientos y Arqueo, y el botón Reimprimir corte.
  • Ventas → Mi turno Cajero y Administrador: resumen del turno propio, exportable a PDF.

Punto de venta

Cajero y Administrador

Abra Ventas → Punto de venta o pulse F9 desde cualquier pantalla. Todas las acciones tienen tecla rápida y también un botón grande para pantallas táctiles.

  • 1Barra del turno con Ingreso, Retiro y Corte Z.
  • 2Campo de captura: escanee o escriba un código, SKU o nombre y pulse Enter. Junto a él, Buscar (F2) y Cliente… (venta a crédito).
  • 3Líneas de la venta: producto, SKU, cantidad, precio e importe.
  • 4Resumen: artículos, subtotal, descuento, total y Cobrar (F12).
  • 5Acciones: cantidad, quitar, descuentos, cupón, abrir cajón y cancelar venta.

Agregar productos

  • Con lector de códigos: escanee; el producto se agrega solo. Si el cursor no está en el campo de captura (pero tampoco en otro campo de texto), la lectura se dirige al campo automáticamente.
  • Por código o SKU: escríbalo y pulse Enter.
  • Por nombre: escriba parte del nombre y pulse Enter o F2. Con varios resultados se abre una lista: muévase con ↑/↓, elija con Enter o salga con Esc.
  • Escanear de nuevo un producto que ya está en la venta suma una unidad a su línea.
AvisoQué hacer
Código no encontrado: …El código es válido pero ningún producto lo tiene. Busque con F2 por nombre o registre el código en el producto.
Código no válido: …La lectura trae caracteres no admitidos o está dañada. Vuelva a escanear o revise el lector en Configuración → Probar escáner.
Lectura ignorada: cierre la ventana para escanearEscaneó con un diálogo abierto. Ciérrelo y vuelva a escanear.

Cambiar la cantidad o quitar una línea

  • Seleccione la línea y pulse F4 (o * con el campo de captura vacío). Escriba la Nueva cantidad. Los productos a granel admiten hasta 3 decimales (por ejemplo 1.250 kg).
  • Para quitar la línea seleccionada pulse Supr o Quitar.
Existencia insuficiente Si vende más de lo que hay, el sistema advierte «La existencia no alcanza para: …» y permite continuar. La existencia queda en negativo y el producto aparece «Sin existencia» en el inventario.

Cobrar

Pulse F12 o Cobrar (F12). Se abre la ventana Cobro con el total.

Efectivo 1

  • Escriba lo que entrega el cliente en Recibido, o use las teclas rápidas: F5 = monto exacto; 1 a 6 = billetes de $20, $50, $100, $200, $500 y $1,000.
  • El sistema muestra el Cambio. Solo el efectivo da cambio.

Tarjeta o transferencia 2

  • Escriba el Monto, elija la forma de pago y, si quiere, la Referencia (número de autorización). Pulse Agregar pago.
  • El sistema solo registra el pago: el cobro se hace en la terminal bancaria. Un pago con tarjeta o transferencia no puede exceder lo pendiente.

Pagos mixtos, nota de crédito y crédito 3

  • Puede combinar varias formas de pago hasta cubrir el total; el indicador muestra «Faltan $…» o el cambio. Para quitar un pago, selecciónelo y pulse Supr.
  • Nota de crédito: escriba el Folio de la nota (por ejemplo NC-000012) y pulse Aplicar; se muestra el saldo disponible y se usa el menor entre el saldo y lo pendiente. Máximo una nota por venta.
  • Venta a crédito: ver Clientes y crédito.

Confirme con Enter, F12 o Confirmar cobro. Esc regresa a la venta conservando los pagos capturados. Al confirmar aparece «Venta V-000123 registrada», se imprime el ticket (si está configurado) y se abre el cajón si hubo efectivo.

Cancelar la venta en curso

Pulse F8 o Cancelar venta (F8) y confirme con Sí, cancelar. Esto solo vacía la venta que está capturando; no afecta ventas ya cobradas (para eso vea el capítulo 8).

Recuperar una venta sin terminar

La venta en curso se guarda después de cada cambio. Si la aplicación se cierra de golpe, se corta la luz o cambia de usuario, al volver a abrir el Punto de venta aparece: «Hay una venta sin terminar con N artículos por $X. ¿Desea recuperarla?». Elija Recuperar o Descartar.

Las líneas de productos que se desactivaron o eliminaron mientras tanto se recuperan señaladas («Producto inactivo» / «Producto eliminado») y hay que quitarlas antes de cobrar.

Abrir el cajón sin venta

Pulse Abrir cajón, escriba el motivo (obligatorio) y confirme. Un Cajero necesita la autorización de un Administrador. Cada apertura queda en la bitácora con su motivo.

Ventas realizadas, cancelaciones y devoluciones

Consultar ventas

Cajero y Administrador

Ventas → Ventas realizadas (o la tarjeta «Ventas del día» de Inicio). Un Cajero solo ve sus propias ventas; el Administrador ve todas y puede filtrar por Cajero.

  • Folio: acepta V-000123, v123 o 123.
  • Estado: Todas, Completadas o Canceladas.
  • Columnas: folio, fecha y hora, cajero, total y formas de pago.

Detalle de una venta y reimpresión

Abra una venta para ver sus productos, pagos (forma, monto, recibido y cambio), descuentos, estado de crédito y el historial de devoluciones. Reimprimir imprime el ticket con la leyenda «REIMPRESIÓN» (y «CANCELADA» si aplica).

Cancelar una venta cobrada

Cancela la venta completa: regresa los productos al inventario y devuelve el dinero.

  1. En el detalle de la venta pulse Cancelar venta.
  2. Escriba el Motivo (obligatorio).
  3. Elija la Compensación: Reintegro (devolver el dinero) o Nota de crédito (vale para una compra futura).
  4. Pulse Cancelar la venta. Un Administrador debe autorizar (también cuando quien opera es Administrador, con su propia contraseña).
Sin el módulo Devoluciones Se conserva la cancelación básica: motivo obligatorio y reintegro, sin notas de crédito ni devoluciones parciales. Un Cajero necesita autorización.

Devolver artículos (devolución parcial)

Módulo: Devoluciones
  1. En el detalle de la venta pulse Devolver artículos.
  2. En la columna A devolver, escriba la cantidad de cada producto (no puede exceder la columna Disponible). Seleccionar todo marca todo lo disponible.
  3. Escriba el Motivo y elija la Compensación.
  4. Revise el Total a devolver y su reparto por forma de pago.
  5. Pulse Devolver y pida la autorización del Administrador.

¿Cómo se devuelve el dinero?

El reintegro se reparte en proporción a las formas de pago de la venta original:

Pago originalQué pasa
EfectivoSale del efectivo del turno abierto actual. Si no alcanza, el sistema lo rechaza: elija nota de crédito o registre un ingreso.
Tarjeta o transferenciaQueda pendiente de reversa manual: haga la devolución en la terminal bancaria y después márquela como reversada en Ventas → Devoluciones y vales.
Nota de créditoEl monto vuelve como saldo a la misma nota.
A créditoReduce la deuda del cliente (ver capítulo 10).
Plazo y reglas Por omisión, solo se aceptan devoluciones de ventas con 30 días o menos (configurable). Un Cajero solo puede cancelar o devolver sus propias ventas. Cada operación recibe un folio D-000001 y queda en la bitácora.

Devoluciones y vales

Solo AdministradorMódulo: Devoluciones

Ventas → Devoluciones y vales tiene tres pestañas:

  • Notas de crédito: busque por folio, filtre Solo con saldo, vea los movimientos de cada nota (emisión, uso como pago, saldo restaurado) y Reimprimir.
  • Reintegros pendientes: devoluciones a tarjeta o transferencia. Después de hacer la reversa en la terminal bancaria, pulse Marcar como reversado y confirme.
  • Configuración: Plazo máximo para cancelar o devolver una venta (1 a 3650 días; 30 por omisión).
Cuidado con las notas de crédito La nota no está ligada a un cliente: cualquiera que presente el folio puede usarla. No se convierte en efectivo y no vence.

Descuentos y cupones

Módulo: Descuentos y promociones

Aplicar un descuento en la venta

  • Descuento de una línea: seleccione la línea y pulse F7 o Descuento (F7).
  • Descuento a la venta: pulse Shift+F7 o Descuento a la venta. Se aplica sobre el subtotal (líneas ya descontadas).

Elija Porcentaje (%) o Monto fijo ($), escriba el Valor, revise el Importe final y pulse Aplicar. Para quitarlo use Quitar descuento. Solo puede haber un descuento por línea y uno por venta.

Límite de descuento Si el descuento supera el límite configurado (10 % por omisión), un Cajero necesita la autorización de un Administrador. Un descuento exactamente igual al límite no la requiere.

Aplicar un cupón

Escriba o escanee el código del cupón en el campo de captura, o pulse Aplicar cupón. El cupón aplica un descuento a la venta y no se combina con un descuento a la venta manual. El uso se cuenta al cobrar; si la venta se cancela por completo, el uso se devuelve.

Administrar cupones

Solo Administrador

CampoReglas

Clientes y crédito

Módulo: Crédito y clientes

Lista y alta de clientes

Cajero y Administrador

Pulse Nuevo cliente y capture Nombre (obligatorio), Teléfono, Email y RUC. En la sección Crédito, el Administrador elige la Modalidad (Solo efectivo o Crédito disponible) y el Límite de crédito. Un cliente creado por un Cajero queda como «Solo efectivo».

Ficha del cliente

Pulse Abrir ficha. Muestra límite, saldo pendiente, disponible y días vencido, con las pestañas Ventas a crédito y Abonos.

Vender a crédito

  1. En el Punto de venta capture los productos.
  2. Pulse Cliente… y elija el cliente (solo aparecen clientes activos con crédito).
  3. Pulse F12 y en el cobro elija Venta a crédito. El total completo queda como pago «A crédito» (no se combina con otras formas de pago).
  4. Confirme. El ticket imprime el nombre del cliente y «A crédito: $X».
Límite de crédito Si el saldo más la venta supera el límite, el cobro muestra «Excede el límite por $X; requiere autorización» y un Cajero necesita la autorización de un Administrador. Si el cliente tiene ventas vencidas, solo se muestra un aviso.

Registrar un abono

Desde la ficha del cliente, pulse Registrar abono:

  1. Revise el Saldo actual.
  2. Escriba el Monto (mayor que 0 y no mayor que el saldo) y elija la Forma de pago: efectivo, tarjeta o transferencia. La Referencia es opcional.
  3. Pulse Registrar. El abono recibe un folio AB-000001 y se imprime el recibo.

El abono se aplica primero a las ventas más antiguas. Se necesita un turno abierto.

Anular un abono

En la pestaña Abonos, elija el abono y pulse Anular. Escriba el motivo; siempre se requiere la autorización de un Administrador. El saldo del cliente vuelve a como estaba. No se puede anular un abono si la venta a la que se aplicó se canceló o devolvió después.

Devoluciones de ventas a crédito

Al cancelar o devolver una venta a crédito, primero se reduce lo que el cliente debe de esa venta. Si ya había pagado de más, el excedente se aplica a sus otras ventas pendientes y solo lo que sobre se le devuelve en efectivo. Estas ventas no admiten nota de crédito.

Solo Administrador

Licencia

El sistema se puede evaluar 30 días con todos los módulos. Faltando 5 días aparece un aviso. Al terminar sin licencia, el sistema pasa a modo lectura: se bloquean el Punto de venta, la apertura de turnos, los reportes y la administración de usuarios; los productos, el inventario y las ventas registradas siguen disponibles, y un turno ya abierto se puede cerrar.

Para activar o extender la licencia Solo Administrador:

  1. Abra Ayuda → Acerca de → Administración de licencia.
  2. Pulse Exportar solicitud… y guarde el archivo .posreq. Envíelo al proveedor.
  3. El proveedor devuelve un archivo .poslic.
  4. Pulse Importar licencia… y elija ese archivo. Se aplica de inmediato, sin reiniciar.
No copie la licencia La licencia está ligada a la computadora. No copie el archivo de licencia a otro equipo: se invalida y el sistema queda en modo lectura.

Respaldos automáticos

El sistema crea un respaldo de la información al abrir o cerrar la aplicación, una vez al día, y conserva los 7 más recientes. Antes de cada actualización de versión también se hace un respaldo. Si al abrir el sistema detecta la base de datos dañada, ofrece restaurar el respaldo más reciente indicando su fecha.

Recomendación Copie periódicamente la carpeta backups (dentro de la carpeta de datos) a una memoria USB o a la nube. Los respaldos automáticos están en la misma computadora y no protegen contra robo o falla del disco.

Cómo tomar las capturas
  • Use una base de datos de práctica para no mezclar datos reales: inicie el sistema con la variable POS_DATA_DIR apuntando a otra carpeta.
  • Mantenga el mismo tamaño de ventana en todas (se recomienda 1366 × 768) y el tema claro.
  • Use datos ficticios pero realistas (nombres, productos, precios).
  • Formato PNG. Nombre del archivo: el código de la figura, por ejemplo IMG-07-01.png.
  • Los wireframes SVG de ejemplo también se exportan a imagenes/wireframes/.
